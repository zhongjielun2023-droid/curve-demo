THE IDEA

One observation leads to the next.

The preceding generation guides the next motion.
Stability in the current generation sets when the robot looks again.

Carry the intended motion.

At a new observation, the unexecuted part of the preceding plan supplies a continuation. Geometry from that same generation guides its direction as the robot forms a fresh action chunk.

Let stability set the reach.

As that chunk takes shape, GRACE reads how consistently its actions are predicted. The stable prefix determines how far the robot proceeds before observing again.

Leave the next continuation.

The completed generation provides the next geometric memory. Actual execution advances the remaining plan, so the next observation begins with a continuation shaped by this motion.
